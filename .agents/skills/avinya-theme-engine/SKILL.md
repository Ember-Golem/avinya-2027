# Avinya 2027 Design & Component Rules
1. Narrative: The user is steering a boat across an archipelago from March 12-14, 2027. Use framer-motion useScroll to move an SVG boat along a nautical path between islands.
2. Component Split: Use Shadcn (Dialog, Sheet, Tabs) for interactive modals and mobile drawers. Use DaisyUI (countdown, steps, timeline) for timers and step indicators.
3. Strict Palette Switching Per Section:
   - Ocean / Hero: Deep abyssal navy (#040814), bioluminescent cyan (#00F0FF), weathered brass (#D4AF37).
   - Day 1 THE LAST OUTPOST (Dune Desert): Spice amber (#D9531E), sandstone (#E6C280), obsidian (#1A110B), Cinzel serif font.
   - Day 2 THE PANDEMONIUM (Synthwave Cyberpunk): Neon magenta (#FF007F), violet (#7928CA), cyan (#00F5D4), Orbitron font, CRT grid.
   - Day 3 THE CARNIVAL ISLAND (Festival Night): Lantern gold (#FFB703), crimson (#E63946), harbor teal (#023047), Fraunces/Playfair font.
   - Hack2Future (Astronaut Space): Orbital void (#020308), starlight silver (#E2E8F0), telemetry orange (#FF5500), Share Tech Mono font.
